# Sitemap Visualizer

A JavaScript application that accepts URLs, discovers their pages, and renders a graph.

## Development and Testing Workflow

This project is edited in GitHub's browser-based VS Code environment and tested through GitHub Pages.

1. Open the repository in [vscode.dev](https://vscode.dev/github/BrintMontgomery/sitemap-visualizer).
2. Make or review changes in the Explorer pane.
3. Save changes with `Ctrl+S`.
4. Open **Source Control** in the left sidebar, enter a concise commit message, and select **Commit & Push**.
5. GitHub Pages deploys changes from the `main` branch. Allow a minute or two for deployment after each push.
6. Test the current deployed version at <https://brintmontgomery.github.io/sitemap-visualizer/>.

When Codex changes the repository, refresh or pull the repository in vscode.dev to receive those changes. When you change files in vscode.dev, commit and push them so Codex can review or extend the current version.
