# Offline Fixtures

These small files support offline imports, tests and the release checks. They describe example sites under `https://example.test/`; the reserved `.test` domain prevents accidental use as a real public target.

- `four-page-links.csv` — directed links for the graph and CSV import checks in Phase 3 and later.
- `four-page-sitemap.xml` — URL inventory for the XML import checks in Phase 4 and later.
- `home-page.html` — local page markup with relative links for the HTML import checks in Phase 5 and later.

The fixtures are test data only. Imports read them locally; the application never fetches `example.test`.

## Graph style reference

![User-supplied graph style reference: orange central root, green hubs, purple outer nodes, and thin gray links on black.](sitemap-graph-reference.png)

`sitemap-graph-reference.png` is the user-supplied visual reference for Phase 8 graph rendering and AT-09 topology/style review. Use a white canvas in place of the reference image's black background, per the user's revised preference. Preserve the prominent orange root, green first-level nodes, purple second-level nodes, thin gray links, and radial clusters around hubs. Node size varies to emphasize the root and hubs. Use readable labels and the persistent legend required by the plan; the screenshot's small text is not an accessibility target. Depth 3+ red and unknown-depth styling remain governed by the requirements.

This image is a design reference, not importable sitemap data or evidence of particular hyperlinks. Actual nodes, edges, and depths must come from the validated graph pipeline.

## Phase 8 rendering fixtures

- `radial-clusters-links.csv` — 49 pages with an orange root, eight green hubs, three purple leaf clusters, red depth 3/4 pages, a cross-link, and a reciprocal pair. Choose root `https://example.test/` and maximum depth 4. This approximate topology tests the reference styling; these are synthetic asserted links.
- `250-node-1000-edge-links.csv` — exactly 250 pages and 1,000 distinct directed asserted links, including cycles/cross-links. Choose the same root, maximum pages 250, and depth 4. Used for bounded layout and later release performance checks; small labels at this scale require zooming.

## Enhanced imports (Phase 15)

Select `home-page.html`, `multi-import-guide.html`, `multi-import-index.xml`, and
`multi-import-child.xml` together. Set their content kinds to HTML, HTML, XML, XML
and map them respectively to `https://example.test/`,
`https://example.test/guide`, `https://example.test/sitemap.xml`, and
`https://example.test/selected.xml`. Set the root to `https://example.test/`.
The index reports the absent `missing.xml` without fetching it. The child supplies
inventory, not links. Enable the hierarchy preview to see path inference while
inventory-only click depths stay unknown. Existing malformed CSV/XML and hostile
HTML fixtures also work in paste mode. Oversize and combined-budget inputs are
generated by `tests/enhanced-import.test.js` to avoid committing large files.
