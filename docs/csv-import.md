# CSV link import interface

`js/csv-import.js` loads after `contracts.js` as a local classic script and exposes `SitemapCsvImport.importFile(file, run)`. It also supports Node tests. Pass a user-selected browser `File` and a `csv-import` run from `SitemapContracts.createRun`. The adapter reads only that file, never makes network requests, and checks its size before reading. The Phase 7 interface will supply the file selection; this phase does not add controls.

The format is comma-separated, with a header containing exactly one `source` and one `target` column (case-insensitive, surrounding whitespace ignored). Additional columns are permitted. Quoted fields may contain commas, line breaks, and doubled quotes. URLs must be absolute HTTP(S) URLs accepted by the shared URL policy. A UTF-8 BOM is accepted. Blank or malformed records are reported by their starting physical line. No formula or other file content is executed.

The returned promise resolves to `{ok: true, acquisition, claims, issues, truncated}` or `{ok: false, issue}`. `acquisition` is the shared validated acquisition result; a future controller must use the shared budget before admitting records. Each normalized directed claim has `source`, `target`, `evidenceClass: "imported-link"`, and an evidence array containing the selected filename and physical row for each assertion, including duplicates. These are user-supplied assertions, not independently verified hyperlinks. Malformed records are skipped and reported with line-specific issues; limits produce explicit partial status. At most 10,000 data records are processed. The graph phase applies page and depth limits and computes graph depth; the adapter does not infer a graph or claim those acceptance checks are complete.
