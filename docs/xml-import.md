# XML sitemap import interface

`js/xml-import.js` exposes `SitemapXmlImport.importFiles(selected, run)` as a local classic script. `run` is an XML import run created by `SitemapContracts.createRun`. `selected` is an array of `{file, sourceUrl?}` records. The first file is the entry sitemap. A source URL is optional for it, but each index reference can resolve only to an expressly selected file with an explicitly matching absolute `sourceUrl`. Duplicate mappings are rejected. Unmapped references are reported; no network request or implicit local path access occurs. Only reachable selected files are read, and cycles terminate. Selection and mapping UI are deferred to later phases.

Successful results contain validated per-file `acquisitions`, `memberships`, index `references`, issues, a status and a truncation flag. Each membership includes its normalized URL, mapped source sitemap URL (or null), local input filename, optional lastmod, `sitemap-only` evidence class, and null depth. Index references and membership records do not assert hyperlinks. A resolved reference means a selected mapping exists, not that the referenced file parsed successfully. Repeated memberships preserve their source evidence for later graph processing.

XML is parsed using the browser's inert `DOMParser`. Before parsing, input is bounded by per-file and aggregate bytes, element count and nesting, with all DTD declarations rejected to prevent entity expansion and external entity access. Entry count and total elapsed time are bounded across the import. Malformed files contribute no records; invalid entries and missing references produce issues. A limit or problem can make the result partial. The graph phase applies the run's page cap and deduplicates records; the XML adapter does not infer links or assign click depth.

Node tests use Python 3's standard-library XML DOM as a development test substitute; the delivered application uses the browser's native parser and has no Python or server dependency. Browser-specific acceptance remains in the release gate.
